# LogiScope · 项目分目标

每个目标都必须有**可验证的验收标准**。没有验收标准的条目是愿望，不是目标。

状态图例：`[ ]` 未开始　`[~]` 进行中　`[x]` 已完成　`[!]` 受阻

> 实机验证的具体步骤见 [`VERIFY.md`](VERIFY.md)。

---

## G0 · 工程骨架跑通　`[x]`

**目标**：项目能编译、能打包、能进游戏加载，为后续所有工作提供地基。

**验收标准**
- [x] `gradlew.bat build` 产出 `build/libs/logiscope-0.1.0.jar`
- [x] jar 内含 `META-INF/neoforge.mods.toml`、`.class`、`lang/*.json`
- [x] 元数据里的 `${}` 占位符被正确替换
- [x] **元数据文件编码为合法 UTF-8**（中文 description）
- [x] 游戏内模组列表能看到 LogiScope

**依赖**：无
**关键风险**：中文导致的编码损坏 —— 已在 `build.gradle` 里用
`filteringCharset = 'UTF-8'` 预先规避。

---

## G1 · 最小可用闭环　`[x]`

**第一轮实机（2026-09-18）通过，逐条结果见 [`VERIFY.md`](VERIFY.md)。**

**目标**：把"按快捷键 → 选一个容器格 → 开始记录 → 看到实时数字"这条链路打通。
这是**整个项目风险最集中的一段**。

**验收标准**
- [x] 打开任意标准容器界面（原版箱子即可），按快捷键能弹出示波器面板
- [x] 示波器里列出该容器的所有槽位（**只列外部设备**，不含玩家背包），含物品名与数量
- [x] 点一个槽位 → 状态变为 `RECORDING`，实时值随物品变化而更新
- [x] 手动物品进出，实时值跟着变（验证数据是真同步的，不是缓存）
- [x] ESC / 再按一次快捷键收起面板 → 原设备界面回来，且**采样不中断**
- [x] 按快捷键之外的键不影响原界面的正常操作
- [x] **在搜索框里打字时绝不弹面板**（原版背包搜索框、JEI 搜索框均通过）
- [x] 默认键位 **`F9`**（功能键不产生字符）；长按不会把面板反复开关（连发去抖）

**依赖**：G0
**关键风险**：CP2（GUI 内按键拦截）、CP3（打开面板不丢菜单）

---

## G1.5 · 面板：可拖动的浮层 + 操作按钮　`[x]`

**第一轮实机通过。**

**目标**：面板是一个能拖到一边的小窗口，而不是盖住整个屏幕；常用操作都有按钮。

**验收标准**
- [x] 面板打开时，**原容器界面仍然完整可见**（不再整屏压黑）
- [x] 按住面板标题栏可以拖动，位置在关闭/重开后保持
- [x] 面板默认落在屏幕右上角，不压住居中的容器界面
- [x] 拖动会被限制在屏幕内，不会拖丢
- [x] 按钮：返回选格 / 暂停 / 继续 / 清空 / 关界面后继续检测（开关）/ 收起
- [x] 按钮在不可用时变灰（例如没有容器界面时"返回选格"不可点）
- [x] 槽位多于面板高度时可滚轮翻页
- [x] 操作有即时反馈（面板上方的临时提示 / 动作栏状态提示）
- [x] 拖动与点击的手感实机确认

---

## G1.6 · 面板外的鼠标交给容器　`[~]`

**目标**：面板只占屏幕一块，其余区域本来就该能操作容器 ——
这也是后面做"图形化框选待测区间"的基础。

**验收标准**（第三轮实机通过；第四轮补齐两处渲染，待复验）
- [x] 点面板以外的位置 → 转交给被压住的容器界面（能拿起/放下物品）
- [x] 拖拽转发（原版快速合成 = 拖过一排格子平均分配）
- [x] 松手转发（不转的话容器的 quick-craft 状态会卡住）
- [x] 滚轮转发（部分模组的容器界面用滚轮翻页）
- [x] 背景容器界面的格子**重新有 hover 高亮**（自己补画，原理见 CP8 之二）
- [x] 背景容器格子**有悬浮提示**（同理补画，见 CP8 之四）
- [x] **光标上的手持物品重新渲染**（第三轮 B7/B8 反馈"图标和数字不见了"，见 CP8 之四）
- [x] 点在面板上但没打中控件时不穿透到容器
- [x] **第三方搜索框守卫**：JEI 搜索框里打字不再弹面板
      （三层守卫，见 `bind/TextInputGuard`）
- [x] 守卫第 3 层的逻辑 bug 已修（第三轮 A7/A10/A12：打过一次字后快捷键永久失效）
- [x] 顺带：创造模式背包里按快捷键不再弹面板
- [x] 默认键位换成 `F9`，从根上消除"打字误触发"这条冲突通道
- [ ] 上述行为逐条实机复验 —— **待第四轮验证**

**已知遗留**：容器的**键盘**操作（数字键换物、`Q` 丢弃、鼠标中键取方块）仍无效 ——
它们走 `hoveredSlot`，而背景层拿不到鼠标坐标（见 CP8）。要修得连 `hoveredSlot` 一起补。

**依赖**：G1.5

## G1.7 · 面板可以推出屏幕　`[x]`

**目标**：GUI scale 调大时逻辑分辨率可能只有 320 宽，而面板固定 272 宽 ——
必须允许把它推出屏幕，否则永远挡着容器界面。

**验收标准**（第三轮实机通过）
- [x] 往左/右拖出屏幕时，至少留 `width/8`（最少 8px）能抓住
- [x] 往下拖出屏幕时，至少留标题栏那一条"拖动条"
- [x] 往上拖时停在屏幕顶部（不允许推到上方）
- [x] 面板越界后**收起再打开会贴回屏幕边缘**（防止它正好压在别的按钮底下点不到）

**依赖**：G1.5

---

## G2 · 波形可视化　`[~]`

**目标**：把时间序列画成能"一眼看懂"的图。

**验收标准**
- [ ] 实时滚动波形，横轴时间、纵轴数量
- [ ] 采样点比像素多时按列取峰值，尖峰不被平均掉
- [ ] 物品类型发生切换的时刻，波形**断开**而不是连线（差值无意义）
- [x] `no_data` 区间在图上表现为**空白断档**，而不是画成 0
- [ ] 纵轴自动缩放，并显示 min/max 刻度
- [ ] 挂机 10 分钟不掉帧（目标 < 1% 帧时间）
- [ ] 能在波形上用鼠标框选一段区间（**依赖 G1.6 的鼠标转发**）

**依赖**：G1
**现状**：火花线已实现（按列取峰值的柱状图 + no_data 留白），
需要升级为带坐标轴的正规波形。

## G3 · 持久身份：跨界面重连　`[x]`

**目标**：关掉界面再打开，探针自动接回同一个容器格；关界面的空档也不丢时间轴。

**验收标准**
- [x] 探头目标能表示成「维度 + 方块坐标 + 槽位下标」
      （`ProbeTarget.dimension/pos` + `ContainerAnchor`）
- [x] 重开同一台设备时，自动识别并恢复记录（`Sampler#tryRebind`）
- [x] 关掉界面后按坐标继续检测，且**用户可选开关**
- [x] 单人：直接读集成服务端的方块实体，拿到真值
- [x] 多人：读不到就记 `no_data`，重开界面那一刻拿到真值，**跨空档的差值仍然有效**
- [x] 无法识别时明确提示（状态显示"已暂停（源丢失）"+ 动作栏提示），
      而不是静默记一堆空样本
- [x] **第一轮实机全部通过**（D1–D11；多人 D12–D15 不作为当前目标）

**依赖**：G1
**遗留**：坐标是靠 `PlayerInteractEvent.RightClickBlock` 推出来的，
**用快捷键开界面的模组推不出来**（锚点为 null → 只能暂停）。这是已知边界。

---

## G4 · 标注与差值计算　`[ ]`

**目标**：能在波形上做标记，并算两段之间的差值。

**验收标准**
- [ ] 单击波形打一个标记点，双击删除
- [ ] 标记显示：所在 tick、物品、数量
- [ ] 选两点 → 显示 Δ数量、Δtick、平均速率（物品/tick）
- [ ] 标记随记录一起导出
- [ ] 标记**独立于环形缓冲**存放（不能因为写满就被覆盖掉）

**依赖**：G2

---

## G5 · 导出与回放　`[ ]`

**目标**：记录能离开游戏继续用。

**验收标准**
- [ ] 导出 CSV：`tick,item_id,count`（`no_data` 用独立标记，不要写成 0）
- [ ] 导出 JSON：含探针信息、起止时间、标注
- [ ] 导出位置在 `.minecraft/logiscope/` 下，文件名带时间戳
- [ ] 能重新载入一份导出文件并在界面上回放

**依赖**：G1（可提前做，不依赖 G3/G4）

---

## G6 · 稳定性与性能　`[ ]`

**目标**：长时间挂机不崩、不卡、不乱。

**验收标准**
- [ ] 连续记录 30 分钟，内存占用平稳（环形缓冲不涨）
- [ ] 环形缓冲写满后，最旧样本被覆盖且界面不报错
- [ ] 玩家死亡 / 换维度 / 断线重连时，采样优雅暂停而非崩溃
- [ ] 关掉界面后长时间 `FOLLOWING` 不泄漏（`WorldProbe` 缓存不堆积）
- [ ] 与其他常见客户端模组（JEI、REI、Jade）共存无冲突
- [ ] 与其他同样使用 GUI 图层栈的模组共存时行为正常

**依赖**：G1
