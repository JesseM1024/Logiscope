## 怎么跑

```bat
cd /d D:\dev\logiscope
gradlew.bat build --offline               :: 出包 -> build\libs\logiscope-0.1.0-1.12.2.jar
dev-check\offline-check.bat               :: ALL_OK（不需要开游戏）
gradlew.bat runClient                     :: dev 运行目录 = 1_12_2_forge\
```

装进实例：删掉 `mods\logiscope-*.jar` → 拷新 jar → 启动。纯客户端模组，服务端不用装。

**准备**：一个存档；一只**大箱子**（双联）；一个 AE2 网络 + **物品终端** + **流体终端**。

## 报问题时的三件套

1. 复现步骤（哪台设备 / 哪条线 / 面板上那几个数）；
2. **`versions\1.12.2-Forge\logs\latest.log`**（含本轮新增的 `[LogiScope] 锚点已绑定：…` /
   `[LogiScope] 打开容器但拿不到锚点…` 两行，锚点有没有一眼就能看出来）；
3. 若是**画面上多了不属于我们的东西**：先按 **F1**，再截一张图 ——
   F1 后消失 = HUD 级（别的模组），F1 后还在 = 屏幕级（那才是我们的责任）。
