## 一、本轮改了什么

| 需求 | 落地 |
|---|---|
| 选格页新增「Probe data」 | 点它进入 DATA 页，**每秒重发一次** `data get block <设备坐标>`，把回执原文显示在面板上半（回执**不再刷聊天框**） |
| 实时结果 → 虚拟容器 | DATA 页底部**一行两格**：`值 / 路径` 与 `名称`。点格子聚焦、直接打字，`Ctrl+V` 可粘贴长路径 |
| 从结果里选值 | 上半结果是解析过的「路径 = 值」清单：**左键数值** = 用它当采样值；**左键文本 / 右键任意项** = 用它当追踪名称（名称跟着 NBT 走） |
| 采样 | 点「开始采样」→ 新建一个**数据探针**（与物品探针同类），**逐 server tick** 读方块实体 NBT 按路径取值 |
| 电力这类没名字的量 | 名称手输（如 `energy`），也可留空（自动用值路径） |

**权限**：`data get block` 需要命令权限；**采样不需要**（服务端直读方块实体）。
没有权限时界面直说"没有命令权限"，手输路径照样能采。

## 二、复测项（★ = 直接对应本轮改动，优先测）

### I. 实时 NBT 显示（★）

| # | 操作 | 期望 |
|---|---|---|
| ★I1 | 选格页选中一台设备 → 点「Probe data」 | 进入 DATA 页（标题 `LogiScope · Probe data`）；上半区出现 `… has the following block data: {…}`；状态显示"已获取" |
| ★I2 | 看聊天框 | **没有**被这条回执刷屏（我们把它吞了） |
| ★I3 | 让设备数值变化（充电 / 灌液） | 上半区的数字**每秒跟着变**（实时刷新） |
| ★I4 | 上半区内容较长 | 滚轮可滚动；右下角显示 `x / y` 行号 |
| ★I5 | 建世界时**不开作弊**，重复 I1 | 状态显示"没有命令权限" + 一行灰字说明；**不报错、不刷聊天框** |

### J. 虚拟容器与选值（★）

| # | 操作 | 期望 |
|---|---|---|
| ★J1 | 点上半清单里的一个**数值**（如 `energy = 1234`） | `值/路径` 格自动填上 `energy`；该行左侧亮起（已选） |
| ★J2 | 点一个**文本**值（如 `tank.FluidName = "minecraft:water"`） | `名称` 格填上 `minecraft:water`，格内右侧出现**品红点**（表示名称来自 NBT） |
| ★J3 | 右键任意一项 | 同 J2（用它的文字当名称） |
| ★J4 | 点 `名称` 格后打字 | 名称变成手输内容，品红点消失（手输优先） |
| ★J5 | 在 `值/路径` 格里 `Ctrl+V` 粘贴 `tanks[0].amount` | 路径被粘进格子 |
| ★J6 | 手动把路径改成不存在的名字（如 `nope`) 后开始采样 | 采到的全是 `no-data`（**不是 0**）—— 这是"读不到就说读不到" |

### K. 逐 tick 采样（★ 本轮核心）

| # | 操作 | 期望 |
|---|---|---|
| ★K1 | 填好 `值/路径` → 点「开始采样」 | 直接进图表页；`now` 行显示当前值；波形逐 tick 出现（与物品探针一样能框选 / 缩放 / 加标记） |
| ★K2 | 让能量 / 流体变化 | 曲线跟着变；**斜率为真**（不是每 tick 才刷一次的阶梯） |
| ★K3 | 打开根页列表 | 新探针在列表里，描述形如 `设备名 · energy · overworld x,y,z`；原来的"选格页空实例"已消失（不留垃圾） |
| ★K4 | 只开 IO 线 | 能量/流体的**每 tick 变化量**（这就是"耗电速率/流速"） |
| ★K5 | 选不同物质的罐（先水后岩浆，或换化学品） | 名称跟着 NBT 变 → 图上**换一条新线**（旧物质那条不再增长），不混淆 |
| ★K6 | 暂停 / 继续 / 清空 / 存档并停止 | 与物品探针完全一致（数据探针共用同一套） |
| ★K7 | 把设备挖掉 / 走远到区块卸载 | 曲线断口 + `no-data` 增长（不写 0） |
| K8 | 多人服务器（无集成服务端） | 状态停在"已暂停"，不假装在记录 |

### L. 回归

| # | 操作 | 期望 |
|---|---|---|
| L1 | 物品探针的全流程（选格 → 完成 → 图表 → 存档 → 回放 → 计算） | 与第十一轮②一致 |

## 三、报问题时的三件套

3. **DATA 页的截图或文字**：状态行 + 你填的 `值/路径` 与 `名称`（这决定了读的是哪个 NBT 键）
