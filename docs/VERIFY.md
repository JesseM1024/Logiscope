## 怎么跑

```bat

:: 或生成脱离 Gradle 的启动脚本（更适合反复重启）
```

**准备**：
1. 一个有产线的存档，含 **原版箱子 / 熔炉** + **MEK 机器** + **精妙存储箱子** 各一台；

3. 一个**超过 2³¹** 的 NBT 数值（如 MEK 能量立方）；
4. 能随手挖掉一台机器（测"换设备"）。

## A. 采样来源与数据保真（第十八轮①）

> 物品探针的采样**统一走服务端直读**（界面开着时也一样）；菜单路径降为兜底
> （多人 / 无坐标 / 无容器能力）。**重点看"界面开着"这一列的读数** ——
> 应全程来自服务端真值，开关界面不会让值"跳一下"或换一套口径。
> 原理：ARCHITECTURE CP9 / CP23 与 2.4。

| # | 操作 | 期望 |
|---|---|---|
| ★S1 | 普通箱子挂探针（选 1~2 格）→ **界面开着**记录几秒 → 关掉界面 → 再记录几秒 | 读数**连续、无缺口、无跳变**；关界面**无任何提示**，值仍是同一条线 |
| ★S2 | 同上，`/tick rate 200`，**界面开着**看图表页采样密度 | 仍是 **200 条/秒**（每 tick 一条）—— 证明界面开着时走的也是服务端 tick，而不是 20/s 的菜单观测 |
| S3 | 「完成」后在图表页（界面仍开着）往箱子放 / 取物品 | 曲线**即时**跟变；无"卡一下"或断线 |
| ★S4 | 开着 A 设备界面记录 → **不关界面，直接打开另一台设备 B 的界面**（把 A 顶掉） | 探针**不暂停**、读数照常。再关掉 B → 记录照常继续（无提示） |
| S5 | 多人（可选，LAN 即可）：开界面记录 / 关界面 | 开界面能读（回退路径）；关界面 `no_data` —— 与旧行为一致 |
| ★S6 | MEK 机器**不开 NBT 追踪**，直接物品探针选 **2 格相同物品**（如 2 格圆石） | 动作栏弹一次 **"槽位下标无法验证"警告**（旧判据从不弹；修正后才出现）。警告后读数可能不是你选的那几格（如实告知；要精确保真请改用 NBT 追踪） |
| S7 | MEK 开 NBT 追踪（开关界面各试一次） | 与之前完全一致 |
| S8 | 精妙存储箱子：选格 → 开关界面看读数 | 与之前一致（普通模组机器下标本就唯一，回退正确） |
| S9 | 把被监测的机器**挖掉** | 该线断开（`no_data`），不是一条假线（回归） |
| S10 | 手动「暂停」一次再「继续」 | 跨暂停断开（gap），恢复后第一笔照算（回归） |

## D. 回放计算：上升 / 下降事件（第十七轮①）

> 「运算」弹窗在「变更区间」之后新增 **上升事件 / 下降事件**（只数增加 / 只数减少）。
> 数量线与 IO 线都可选。原理：ARCHITECTURE C19-6 与 PROGRESS-HISTORY 第十七轮①。
> **准备**：一个回放存档，最好同时有物品线与 IO 线、区间里有升降交替；另有一条只升不降的线。

| # | 操作 | 期望 |
|---|---|---|
| ★H1 | 回放，框选一段**升降交替**的区间 → 运算选「上升事件」（数量线） | 首行 = `上升 N 次`，只数**增加**的变化；下方 `变化量 mean/var` 与 `周期 mean/var`；**周期 = 相邻两次上升之间的 tick 间隔**（与「变更区间」的周期不同） |
| ★H2 | 同一区间切「下降事件」 | 只数减少的；变化量 mean 带负号；周期同理 |
| ★H3 | 换一条**只升不降**的线选「下降事件」 | `下降 0 次`，**不出现** delta / period 两行 |
| ★H4 | 同一区间对照三个运算 | `变更次数 = 上升次数 + 下降次数`（断档处三项都不计） |
| ★H5 | IO 线选「上升 / 下降事件」 | 与数量线口径一致；**段起点的第一笔流量照算** |
| H6 | 手动暂停一次再继续，框选跨暂停的区间 | 跨断档的变化**不算**事件；三个事件运算口径一致 |
| H7 | 小数线（流体 mB/t 这类） | 按符号正常计数；`+0.5` 这类小变化也照算一次（非零即事件） |
| H8 | 运算弹窗本身 | 共 **7 项**（关闭 / 极值 / 简单统计 / 变化总量 / 变更区间 / 上升 / 下降）；中英文案正常（Rise / Fall events） |
| H9 | 既有运算回归（抽样） | 极值 / 简单统计 / 变化总量 / 变更区间 数值与上一版一致 |

## 报问题时的三件套

1. **复现步骤**（哪台设备 / 哪条线 / 框了哪一段 / 面板上那几个数）；
2. **`run/logs/latest.log`**；
3. **能对上的数字**：存量线的统计 vs IO 线的统计、或状态行（`ticks N  no-data M`）——
   数据层问题几乎都藏在"两个数对不上"或"该断没断"里。
