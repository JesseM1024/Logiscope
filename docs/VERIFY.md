## 一、本轮改了什么（先说结论，再给复测项）

用户实测反馈（20t 正常流速，不是极端场景）：

| 现象 | 根因 | 改法 |
|---|---|---|
| **曲线偶发断线**，两侧数据都正常 | 样本时间戳来自**服务端权威 gameTime**，而客户端每秒最多观测 20 次、服务端也每秒走 20 tick，两者**不锁相**：一次帧抖动就让某个客户端 tick 看到 +2 的世界 tick（少观测一格）。旧规则"间隔 > 1 就断"把这种**采样稀疏**当成了断档 → 凭空剪一刀 | 断线改由**显式标记**决定：`no_data`（读了读不到）/ `gap`（没在记录）/ 该物品在上一个数据 tick 里缺席；观察抖动造成的小空档**不再断开**。另留一条"静默大空档（>20t）"兜底 |
| **断线之后还有一个 1 tick 的曲线平台**（不是手动启停容器造成的） | 世界侧异步读值被**复用**（`maxAge` 允许缓存多待几个客户端 tick），却贴上了新的 tick 标签 → **同一个观测被写成两条样本** → 一个 1t 平台。关/开界面的"垫值"（lastViews/seed）同理 | 读结果带上"这次观测的身份"（提交读取时的客户端 tick），**同一个观测只写一次**；没拿到新观测的这一 tick **什么都不写**（时间轴留空档，按新规则连线）。删掉 lastViews / seed 那套垫值逻辑 |
| 纵轴上一排刻度全是 `1.79E6` | 科学计数法只留 2 位小数，`1786000` 和 `1786500` 印出来一样 | 纵轴精度提到 3 位小数，并把**步长顶到"相邻标签不是同一个字符串"**为止（宁可刻度稀疏，也不要一排看不懂的数字） |
| 读数（框选统计、十字线）给的是 `1.79E6` | 短格式被用到了读数上 | **只有纵轴**用科学计数法；框选统计 / 十字线读数 / 面板 `now` 与 `min/max/avg` 一律**精确整数** |

顺带一处诚实性变化：**暂停现在会在曲线上留一个真正的断开**（写一条 `gap` 标记），
恢复之后那一段不会被连起来 —— 但它**不计入 `no-data`**（那是"读了读不到"的专属计数）。

## 二、本轮复测项（★ = 直接对应本轮改动，优先测）

### A. 断线与平台（★ 本轮核心）

| # | 操作 | 期望 |
|---|---|---|
| ★X1 | 挂一个**大数量容器**探头，保持 20t 正常流速，记 5 分钟以上（开着图表页看实时滚动） | **不再出现"凭空断线"**。曲线该连的地方是连续的（`/tick rate` 保持 20） |
| ★X2 | 同上，重点看断线处 | 即使偶发漏观测一格，也**只是折线跨过一格**，不会出现 1 像素的断口 |
| ★X3 | 断线后紧跟的那一段 | **不再有 1 tick 的平台**（同一个值贴两个 tick 标签）。曲线是单调下降/上升的，斜率一致 |
| ★X4 | 把光标移到某个断口上 | 读数显示 `-`（十字线的"没有观测"语义）—— 这就是断口的成因：那里确实没观测到 |
| ★X5 | `/tick rate 200` 挂一会儿（可选，验证旧规则的另一面） | 采样稀疏（约每 10t 一个点），但**曲线是连的**，不是一串孤立点 |
| ★X6 | 关掉容器界面（转坐标跟踪） | 接缝处**不冒出假 `no_data`**；中间可能少一两格观测，但线是连的 |

### B. 暂停与恢复

| # | 操作 | 期望 |
|---|---|---|
| ★X7 | 记录中点「暂停」等几秒 →「继续」 | 恢复之后曲线**在暂停处断开**（不会被连起来） |
| ★X8 | 同上，看统计行 | `no-data` **不因为暂停而增加**（暂停是 `gap`，不是读失败） |
| ★X9 | 自动暂停（例如记录中把被监控的容器拆掉 / 换成别的界面） | 同样断开且不计入 `no-data` |

### C. 纵轴与读数精度（★）

| # | 操作 | 期望 |
|---|---|---|
| ★X10 | 测百万级容器，缩放到只剩几十 tick 的窗口 | 纵轴刻度**不再是同一个字符串**（例如 `1.786E6` / `1.787E6`）；刻度可能变稀疏，这是刻意的 |
| ★X11 | 框选一段区间 | 统计块里的首值/末值/Δ 是**精确整数**（如 `1793280→1793088  Δ-192`），不是 `1.79E6` |
| ★X12 | 鼠标停在波形上 | 十字线读数后面跟的是**精确整数** |
| ★X13 | 看面板上的 `now` 与 `min/max/avg` | 同样是精确整数（位数变长，窄面板下会自动裁断，不会压到右边的数字） |

## 三、报问题时的三件套

1. **复现步骤**（哪台设备、哪一格、点了什么）
2. **`run/logs/latest.log`**
3. **面板上的关键数字**：`ticks N  no-data M` / `now` / `switch N  series M`
   —— 波形问题再补一条：**把光标停在可疑处**，念一下读数（`-` = 那里没有观测）。
