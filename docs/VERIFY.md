# LogiScope · 实机验证清单（1.12.2 线）

> 版本 `0.1.0-1.12.2`，jar 已装进 `1.12.2-Forge` 实例（构建基线 Forge 14.23.5.2859 /
> 实例是 2864，只差官方小版本，二进制兼容）。
> **本线是全新移植**，下面每一条都是"第一次跑"，不是回归。
> ★ = 优先项（坏了就没法用）；其余是完整性检查。

## 怎么跑

```bat
cd /d D:\dev\logiscope
gradlew.bat build                         :: 出包 -> build\libs\logiscope-0.1.0-1.12.2.jar
dev-check\offline-check.bat               :: ALL_OK（不需要开游戏）
gradlew.bat runClient                     :: dev 运行目录 = 1_12_2_forge\
```

装进实例：删掉 `mods\logiscope-*.jar` → 拷新 jar → 启动。纯客户端模组，服务端不用装。

**准备**：一个有产线的存档；一个**大箱子**（≥ 27 格）；一台有 NBT 数值的机器（MEK / TE 都行）；
一个 AE2 网络（只需确认"装着它也不炸"，本线**不做** AE 监视）。

## A. 快捷键与"压层"（本线最大的未知）

| # | 操作 | 期望 |
|---|---|---|
| ★A1 | 打开箱子 → 按 **F9** | 面板出现。**关键：箱子界面没有被关掉**（1.12.2 没有图层栈，这是最容易炸的一条） |
| ★A2 | 看面板背后 | 能看见箱子的界面（我们自己替它画），不是黑屏 |
| ★A3 | 再按 F9（或 Esc） | 面板收起、**回到箱子界面**，还能继续拿放物品 |
| A4 | 面板开着时点面板外的空白 | **没反应**（已知限制：`GuiContainer#mouseClicked` 是 protected，跨包转交不了） |
| A5 | 关掉箱子 → 在世界上按 F9 | 面板独立打开（背后是游戏画面）；再按 F9 回游戏，鼠标重新锁住 |
| A6 | 准星指着箱子按 F9 | 自动打开箱子界面 + 压上面板（"指哪测哪"） |
| A7 | 准星指着**没有任何界面的机器**按 F9 | 直接进入该设备的创建流程（不发右键交互） |
| A8 | 在 JEI 搜索框里打字时按 F9 | 面板照常弹出（F9 是功能键，永不被"正在打字"挡） |
| A9 | 把快捷键改成一个字母（选项→控制），开容器后按它 | **不弹面板**（会打字的键在有界面时让路）；关掉界面后按它才弹 |
| A10 | 打开聊天框打字时按 F9 | 面板弹出（`GuiChat` 只挡非功能键） |

## B. 选格页

| # | 操作 | 期望 |
|---|---|---|
| ★B1 | 大箱子里进选格页 | 列出所有非玩家背包的格子，数量与物品名正确 |
| ★B2 | 勾 3 格 → 「完成」 | 只测这 3 格；面板上三条线 |
| B3 | 筛选框敲 `iron` / `#1` / `#1 iron` | 与另外三条线一致（`#1` 不命中 `#10`） |
| B4 | 打开「忽略空槽」再敲筛选词 | 两条件叠加；Esc 只清文字 |
| B5 | 可视化选格（框选容器格子） | 高亮框画在格子上、不遮住物品图标 |
| B6 | 拖大窗口缩放 / 面板拖到边缘 | 面板不会跑到屏幕外（每次打开会贴边收回） |

## C. 采样与图表

| # | 操作 | 期望 |
|---|---|---|
| ★C1 | 选定一格开始测 | 存量线随箱子内容变化；IO 线能看出尖峰 |
| C2 | 把物品拿空再放回 | 0 与恢复都如实画；换物品那一瞬线**断开**（不是从 64 连到 1） |
| C3 | 走远让区块卸载 | 线断开、状态行 `no-data` 增长（不是画成 0） |
| C4 | 图例 / 纵轴刻度 | 名字与数值可读，大数用科学计数法，不溢出面板 |
| C5 | 滚轮缩放 / 框选一段 | 与另外三条线一致；**面板内**滚轮有效 |

## D. DATA 页（NBT 取数）

| # | 操作 | 期望 |
|---|---|---|
| ★D1 | 对一台机器进 DATA 页 | 列出 NBT 路径，点一条能看到实时值 |
| D2 | 右键一条数值路径 | 标记「按数值读取」，值格可编辑 |
| D3 | 刷新滑条 | 1 秒档自动刷新；拖到最左（0）= 不刷新，只剩「刷新」按钮 |
| D4 | 关掉界面后 | 探针仍按 NBT 路径读数（服务端侧） |

## E. 回放与归档

| # | 操作 | 期望 |
|---|---|---|
| E1 | 录一段 → 根页点存档 → 回放页 | 波形正确重放，上升/下降事件能算出来 |
| ★E2 | 回放页「打开存档文件夹」 | 直接打开那一次的目录（`mcDataDir\logiscope\<名>\`），能看到 csv/json |
| E3 | 根页「打开文件夹」 | 打开 `logiscope\` 根目录（走 `java.awt.Desktop`，打不开只记日志） |

## F. 与模组共存（实例里已装 AE2 rv6 / TE / MEK / JEI）

| # | 操作 | 期望 |
|---|---|---|
| F1 | 打开 AE2 终端 | 面板照常能开（AE 模式不触发，选格页按普通容器处理） |
| F2 | 打开 MEK 机器 | 无容器槽位时自动进 NBT 追踪并提示（判据 = 注册命名空间 `mekanism`） |
| F3 | 装 JEI 的搜索框 | 不影响快捷键（见 A8） |

## 报问题时的三件套

1. 复现步骤（哪台设备 / 哪条线 / 面板上那几个数）；
2. **`versions\1.12.2-Forge\logs\latest.log`**（1.12.2 的日志是 UTF-8，可直接看）；
3. 有没有 `[LogiScope]` 开头的 WARN / 异常 —— 尤其 `压浮层`、`AE` 这两类。
