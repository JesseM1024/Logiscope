### C-4. DATA 页右键「按数值读取」填入值格（[1.20.1] 轮次 4；实机两轮反馈后定稿）

> 值列表上**右键** = 把该路径按「按数值读取」口径**填入值格**（不直接加入追踪）——
> 用于"数值被模组存成字符串"的键，如 `"energy": "1000"`；填好后可先设名称、
> 再点「确认添加」。值格右端点**黄色小方格** = 该口径（名称格品红点语义不变）；
> 手改路径 / 左键取值 → 黄标消失（回到自动口径）。
> 不可转换 → 采样照常记 `no_data`（宁缺毋假，不垫 0）。
> 同路径已在追踪中：设置变了（口径 / 名称）再确认 = **替换**；设置没变才提示"已在追踪中"。
> 原理：ARCHITECTURE CP26 的 C26-1（`asValForced` / `parseNumericText`）。

**造一个字符串数值键**（没有现成设备时）：对着一只箱子执行
`/data modify block <箱子坐标> CustomEnergy set value "1000"` —— 箱子 BE 的 NBT
顶部会出现**字符串**键 `CustomEnergy`，DATA 页原文区可见 `"1000"`（带引号）。

| # | 操作 | 期望 |
|---|---|---|
| ★P1 | 对一个**字符串**值（原文带引号，如 `"1000"`）**右键** | 提示"已按数值读取填入：<路径>"；路径进**值格**、右端点出现**黄色小方格**（**不**直接加入追踪） |
| ★P2 | 对 P1 填好的路径点「确认添加」→ 采样 | 列表出现该目标、**曲线出数**（`"1000"` 解析成 1000），**不是** no-data |
| ★P3 | 直接对 **MEK 等设备的字符串数值键**（如 `"39900"`）走 P1→P2 | 同 P1 / P2：填入 + 出数正常 |
| P4 | 对**不可转换**的字符串（如 `"abc"`）右键 → 确认添加 | 能加入追踪；采样全程 `no_data`（不伪造 0） |
| P5 | 对一个**数值**值（无引号）右键 → 确认添加 | 结果与左键取值 + 确认完全一致（数值标签照常读；黄标只是显式口径） |
| P6 | 右键填入后，手动改动值路径（打字 / 粘贴 / 退格）或左键点数值取值 | **黄标消失**（回到自动口径）；再右键可重新标 |
| P7 | 对**已在追踪中**的同路径：右键填入（改名称 / 带黄标）→ 确认 | **替换**旧目标（不出现重复行），提示"已更新追踪"；设置完全没变则提示"已在追踪中"、不折腾 |
| P8 | 对一个**列表 / 复合**条目右键 | 提示"该条目不是单个值（列表 / 复合），无法作为数据追踪：<路径>"，**不填入** |
| P9 | 左键回归 | 左键 数值 = 取值路径（进值格，无黄标）；左键 文字 = 当名称（品红点）—— 与之前一致 |

## D. 回放计算：上升 / 下降事件（第十七轮①）

> 「运算」弹窗在「变更区间」之后新增 **上升事件 / 下降事件**（只数增加 / 只数减少）。
> 数量线与 IO 线都可选。原理：ARCHITECTURE C19-6 与 PROGRESS-HISTORY 第十七轮①。
> **准备**：一个回放存档，最好同时有物品线与 IO 线、区间里有升降交替；另有一条只升不降的线。

| # | 操作 | 期望 |
|---|---|---|
| ★H1 | 回放，框选一段**升降交替**的区间 → 运算选「上升事件」（数量线） | 首行 = `上升 N 次`，只数**增加**的变化；下方 `变化量 mean/var` 与 `周期 mean/var`；**周期 = 相邻两次上升之间的 tick 间隔**（与「变更区间」的周期不同） |
| ★H2 | 同一区间切「下降事件」 | 只数减少的；变化量 mean 带负号；周期同理 |
| ★H3 | 换一条**只升不降**的线选「下降事件」 | `下降 0 次`，**不出现** delta / period 两行 |
| ★H4 | 同一区间对照三个运算 | `变更次数 = 上升次数 + 下降次数`（断档处三项都不计） |
| ★H5 | IO 线选「上升 / 下降事件」 | 与数量线口径一致；**段起点的第一笔流量照算** |
| H6 | 手动暂停一次再继续，框选跨暂停的区间 | 跨断档的变化**不算**事件；三个事件运算口径一致 |
| H7 | 小数线（流体 mB/t 这类） | 按符号正常计数；`+0.5` 这类小变化也照算一次（非零即事件） |
| H8 | 运算弹窗本身 | 共 **7 项**（关闭 / 极值 / 简单统计 / 变化总量 / 变更区间 / 上升 / 下降）；中英文案正常（Rise / Fall events） |
| H9 | 既有运算回归（抽样） | 极值 / 简单统计 / 变化总量 / 变更区间 数值与上一版一致 |

1. **复现步骤**（哪台设备 / 哪条线 / 框了哪一段 / 面板上那几个数）；
2. **`1_20_1_neo/logs/latest.log`**（外部实例侧 = `.minecraft/versions/1.20.1-NeoForge/logs/latest.log`）；
3. **能对上的数字**：存量线的统计 vs IO 线的统计、或状态行（`ticks N  no-data M`）——
   数据层问题几乎都藏在"两个数对不上"或"该断没断"里。
