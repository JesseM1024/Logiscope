## 一、本轮改了什么

| # | 审查发现（P1） | 修法 |
|---|---|---|
| 1 | **IO 线统计吞掉每个数据段的第一笔真实流量、还谎报一次断档**（实测：存量 10→14→12 时 IO 报 `上升=0 断档=1`，存量报 `上升=4 断档=0`） | 那个 `breakBefore` 是**渲染**要的断线标记，统计不再拿它当"值不可信"：IO 的上升/下降/**变更事件照单全收**，缺口数改为"真的少了几笔 Δ" |
| 2 | NBT 数值窄化进 `int`：>2³¹ 回绕成负数、NaN → 0（都是"错值当真值"） | 越界/非有限一律按**读不到**处理（留空）；`Snbt` 不再接受 `NaN`/`Infinity` 字面量 |
| 3 | 纯数据探针**暂停不写 gap 标记** → 恢复后曲线跨过暂停连线 | 水位取"物品路 / 数据路"两条的较后者 |
| 4 | `configure()` 与在飞的服务端采样**竞态** → 新会话第一格写旧设备的值 | 采样在锁内**重取目标**并把守卫一起重算 |
| 5 | `readSlotAnchor` 把"设备早没了"也写成 0（一条永远为 0 的假曲线） | **方块实体类型比对**（C24-10）：还是那台设备 → 0；换了 → `no_data` |
| 6 | 跨世界静态残留：`ContainerAnchor.clearActive()` / `ProbeSlots.reset()` 有定义无调用 | 进世界（`LoggingIn`）与探针清空一起调 |
| 7 | 重命名框离开回放页不释放焦点 → **整个键盘被吞** | 按键入口按"页面还在不在"兜底清焦点 |
| 8 | `readHeader` 名义"只读几 KB"、实际整份解析（含几万条样本） | 改成**流式读**（`JsonReader`：认识的键取值，`samples` 整段跳过） |

**离线代理指标**（`dev-check/TestChart`，336 → **376 条**）：

| 断言 | 修复前 | 修复后 |
|---|---|---|
| 存量 10→14→12 的 IO 统计 | 上升 0 / 断档 1 / 事件 1 | **上升 4 / 断档 0 / 事件 2** |
| 中间断一次（104 缺格）再继续 | 上升 0 / 断档 2 | **上升 4 / 下降 −4 / 断档 1（真的那一次）** |
| `slot:NaN` / `slot:99999999999` | 被当成槽位号（0 / MAX_VALUE） | **不认这个列表**（宁可不识别，不给错号） |
| 存档头部读取 | 整份解析 | 流式（小结数值与写入一致，坏文件抛 `IOException`） |

## 二、复测项（★ = 本轮重点）

### A. 数字对不对得上（★ 数据保真）

| # | 操作 | 期望 |
|---|---|---|
| ★A1 | 一条**连续**记录（中途不暂停），框选一段看 IO 线的统计 | `上升/下降` 与**存量线**同区间的变化一致；**不出现"断档"那一行**（修复前每个数据段必报 1 处） |
| ★A2 | 同上，比较两行的 `合计`（net） | IO 的 `net` == 存量线的区间 Δ（无断档时**必须相等**） |
| ★A3 | 手动「暂停」一次再「继续」，再框选跨过暂停的那一段 | IO 的**断档数 = 1**（暂停期间那一笔 Δ 真的没测到），而**恢复后的第一笔 Δ 照算**（不再被当成断档丢掉） |
| A4 | 看 IO 线的「变更」事件数 | = 非 0 的流量点数（含段首那一笔） |

### B. 装不下的数（★ 别把错值写进曲线）

| # | 操作 | 期望 |
|---|---|---|
| ★B1 | 用 `Probe data` 追一个**超过 2³¹** 的 NBT 数值（如能量立方的 FE / AE 能量） | 该目标**留空**（线上断开 / 不出现读数）；**不出现负数、也不出现 0**（修复前会回绕成负数） |
| B2 | 换成正常范围（< 2³¹）的同一路径 | 正常有读数（别把正常值也当可疑） |

### C. 暂停该断就断（★）

| # | 操作 | 期望 |
|---|---|---|
| ★C1 | **只做数据探针**（`Probe data` 加目标、不选格子）→ 记一会儿 → 暂停 → 继续 | 暂停前后**断开**（不跨过暂停连成一条）。修复前纯数据探针暂停时**什么都不写**，恢复后是一条假连续线 |
| C2 | 物品探针暂停 → 继续（老行为） | 照旧断开（不该回退） |

### D. 换设备 = 读不到（★）

| # | 操作 | 期望 |
|---|---|---|
| ★D1 | NBT 槽位跟踪进行中，把机器**挖掉**（或换成别的方块） | 该线**断开**（`no_data`），而不是一条永远为 0 的假线 |
| ★D2 | 还是那台机器，只是把某个被监测的格子**抽空** | 该线 **0**（不是断档）—— 上一轮 N14 的行为必须保持 |
| D3 | 换相**同型号**的新机器（同类型方块实体） | 视为同一台（按类型比对），读数接着走（这是有意的口径，见 C24-10） |

### E. 跨世界 / 键盘 / 存档

| # | 操作 | 期望 |
|---|---|---|
| ★E1 | 换存档或重进世界后，对着**新世界的新容器**打开面板 → 选格页 | 不把它认成上个世界那台设备（信息行/槽位清单不张冠李戴） |
| ★E2 | 回放页点「重命名」→ **点「返回列表」**（不要按 Esc）→ 按任意键（`E` / 方向键 / 数字键） | 键盘**一切正常**（修复前会被整个吞掉，只能按 Esc 救） |
| E3 | 存档多、单个存档很大的情况下打开面板 | 打开不再有明显卡顿；列表里的**样本数 / 标记数 / 时间范围**正确 |
| E4 | 导出后立刻看根页存档列表 | 新存档**立刻出现**（列表不会漏刷新） |
