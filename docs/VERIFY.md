## 一、本轮改了什么

| 需求 | 落地 |
|---|---|
| 计算 quantity 或 IO 的开关（一次算一个） | 回放页工具栏新增「计算 数量 / IO」chip，点击切换；**没选中曲线时置灰** |
| 数学运算按钮 + 运算列表 | 工具栏新增「运算 <当前>」chip，点击弹出 5 项列表：关闭 / 极值 / 简单统计 / 变化总量 / 变更区间 |
| 四种运算 | **极值**：min/max（含所在 tick）；**简单统计**：mean / med / var（总体方差）；**变化总量**：上升 Σ + 下降 Σ = Δ（断档处不计、单独报缺口数）；**变更区间**：变更次数 / 变化量 mean·var / 周期 mean·var（周期 = 相邻两次变更的 tick 间隔） |
| 框选后自动出结果 | 结果框画在绘图区**右上角**（框选统计在左上角，两块并存互不影响）。结果随「区间 × 曲线 × 对象 × 运算」四元组缓存，静止时零开销 |
| 计算引擎 | 新纯类 `analysis/CurveMath`（不引用游戏类，离线断言覆盖） |

**IO 的段内口径**：只统计**严格在段内**发生的变化——段首采样那个 tick 的流量是从区间外带进来的，算进去会与 Δ 对不上。

**断档的诚实性**：Σ升+Σ降 在有断档时**故意 ≠ Δ**——断档处的变化没留在任何一次观测里（CP18 的老边界），结果框会报"断档 N 处未计入"，而不是悄悄让它对上。

## 二、复测项（★ = 直接对应本轮改动，优先测）

### F. 回放计算（★ 本轮核心）

| # | 操作 | 期望 |
|---|---|---|
| ★F1 | 选中曲线后看工具栏 | 多出「计算 数量」「运算 关闭」两个 chip；未选曲线时两块置灰 |
| ★F2 | 点「计算 数量」 | 切成「计算 IO」；再点切回（一次只算一个） |
| ★F3 | 点「运算」 | 弹出 5 项列表，当前项品红方块；选中后弹窗关闭、chip 文案更新 |
| ★F4 | 运算=关闭 | 不出结果框（关闭 = 不算） |
| ★F5 | 框选一段 → 运算=极值 | 右上角结果框：`min n @t…` / `max n @t…`，与波形读得出来的一致 |
| ★F6 | 运算=简单统计 | `mean / med / var` 三行；对恒定曲线 var=0 |
| ★F7 | 运算=变化总量 | `上升 +x / 下降 -y / 合计 Δ…`；无断档时 合计 == 框选统计里的 Δ |
| ★F8 | 运算=变更区间 | `变更 N 次 / 变化量 mean·var / 周期 mean·var`；"7 过一会变 8 再变 9"这类曲线应给出 变化量 mean=1 var=0 |
| ★F9 | 切「计算 IO」重复 F5–F8 | IO 的极值带正负号；变化总量 = 正流量 Σ + 负流量 Σ（无断档时 == Δ） |
| ★F10 | 框选一段**跨过暂停/断档**的区间 | 变化总量多一行"断档 N 处未计入"；此时 Σ升+Σ降 ≠ Δ 是**对的** |
| ★F11 | 框选期间（拖动中） | 不出结果框；松手才出 |
| ★F12 | 左上角的框选统计块 | 始终在，不被结果框覆盖（右上角） |
| F13 | 切换运算/对象/重新框选 | 结果框内容跟着变，无残留 |
| F14 | 「分析」取消选中（弹窗再点一次分析） | 两个 calc chip 置灰、结果框消失 |
