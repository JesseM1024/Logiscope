## 一、本轮改了什么

| 需求 | 落地 |
|---|---|
| 框选统计删掉 `in` / `out` | 区间读数里已经有 `Δ`（首尾之差），`in+out` 是表达同一件事的第二份数字。**数据还在 `Series#flow` 里**，要捡随时能重算 |
| 图例里 `(empty)` 不再需要 IO | 空格子没有进出可言：IO 线不画、弹窗里也没有 IO 这一项 |
| 仅启用 IO 线时十字线也要有读数 | 之前只开 IO（存量线关掉）的物品在十字线读数里**彻底消失**；现在读数形如 `barrel Δ+64` —— 名字 + 这个 tick 的净流量，不报存量 |
| IO 并入物品图例 | 图例条**一个物品一格**（条目数减半）；点它弹出「数量 / IO」两项小菜单，两项分别控制存量线与 IO 线。弹窗顶边是物品色，状态色块开=线色 / 关=灰（与图例同语汇） |

## 二、复测项（★ = 直接对应本轮改动，优先测）

### A. 图例弹出菜单（★）

| # | 操作 | 期望 |
|---|---|---|
| ★A1 | 点任意物品图例块 | 弹出「数量 / IO」两项菜单；顶边一条物品色；状态色块：开=线色（IO 浅一档）、关=灰 |
| ★A2 | 点「数量」 | 存量线开关切换（图例块灰/亮同步）；**菜单不关**，好连着切 IO |
| ★A3 | 点「IO」 | IO 线开关切换；0 基线 / 纵轴自动缩放行为与上一轮一致 |
| ★A4 | 点 `(empty)` 的图例块 | 弹窗里**只有「数量」一项**，没有 IO |
| ★A5 | 再点同一图例块 / 点面板上其他任何地方 | 菜单关闭 |
| A6 | 菜单开着时点波形区 | 菜单关闭，且这次点击**不**触发框选（点在菜单外的点击被吃掉） |
| A7 | 菜单盖住底部按钮时点菜单行 | 只切换菜单项，按钮**不**被误触（菜单画在按钮之上） |
| A8 | 菜单开着时该物品消失（换物品 / 清空记录 / 切换探针） | 菜单自动收起，不残留 |

### B. 读数瘦身（★）

| # | 操作 | 期望 |
|---|---|---|
| ★B1 | 框选一段区间 | 统计块每行形如 `iron_ingot 100→220  Δ+120  0.400/t`，**没有 in / out** |
| ★B2 | 只开 IO 线（把存量线关掉）后光标停在图上 | 读数形如 `barrel Δ+64` —— 有名字、有 Δ，**没有存量数字** |
| ★B3 | 存量 + IO 都开 | 读数形如 `iron_ingot 1793280 Δ-64`（与上一轮一致） |
| B4 | 面板 `now` 行 | 开了 IO 的物品后面仍跟 `[±n/t]`，不受本轮影响 |

### C. 回归

| # | 操作 | 期望 |
|---|---|---|
| C1 | 图例条 | **一行一个物品**（条目数减半）；超过 3 行仍收成 `+N` |
| C2 | 框选 / 冻结 / 缩放 / 实时 / 全览 | 与第十轮⑤一致，无回退 |
| C3 | 20t 与 `/tick rate 200` | 采样密度与 `ticks` 计数不变（第四次修复的成果） |
