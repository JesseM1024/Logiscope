# LogiScope · 实机验证清单

> 这份是**给手用的**：照着做一遍，逐条打勾或记下现象。
> 目标定义见 [`GOALS.md`](GOALS.md)，原理见 [`ARCHITECTURE.md`](ARCHITECTURE.md)。

## 怎么跑

```bat
cd /d D:\dev\logiscope
gradlew.bat runClient
```

或生成脱离 Gradle 的启动脚本（更适合反复重启测试）：

```bat
gradlew.bat createLaunchScripts
build\moddev\runClient.cmd
```

**准备**：创造模式 + 一个箱子 + 几组物品（建议两组不同物品，比如铁锭和铜锭）。

**当前 `run/mods/` 里装的**：`jei-1.21.1-neoforge-19.21.2.313.jar`（测搜索框冲突必须要它）。

> ⚠️ **快捷键**：代码里的默认值是 **`F9`**，但 `run/options.txt` 里存着你设的
> `key_logiscope.key.open_scope:key.keyboard.right.bracket` ——
> **实机生效的是 `]`**（存档优先于代码默认值）。下面的清单统一写作 `]`。
> 想换回 F9 就去「选项 → 控制 → 物流示波器」改，或删掉 `options.txt` 里那一行。

| F10 | 图例超过 3 行时，多出来的会收成 `+N`（点不到） | 一个槽位同时出现 7 种以上物品很罕见；需要时把面板拖大即可 | 已接受 |
| F11 | 纵轴范围会随窗口滚动偶尔跳一下 | 已吸附到整数刻度，跳变频率远低于逐帧抖动 | 已接受 |

## 发现问题时怎么反馈

把这三样一起给出，定位速度差 10 倍：

1. **复现步骤**（哪一格、按了什么键、点了哪里）
2. **游戏日志**（`run/logs/latest.log`）
3. **面板上的关键数字**：`状态` / `samples X  no-data Y` / `now` / `switch N  series M`

如果是按键/界面问题，再补一条：**当前绑定的键位是什么**（选项 → 控制里看）。
如果怀疑第三方搜索框没被拦住，把**那个搜索框所属模组的名字和版本**也带上 ——
`TextInputGuard` 里每支持一个搜索类模组都要单独加一个探针（目前只接了 JEI），见该文件注释。
如果是波形画得不对，最有用的信息是：**框选那段出问题的区间**，然后把统计块里的数字念一遍 ——
那几行数字直接对应数据层，能立刻判断是"数据错了"还是"只是画错了"。
