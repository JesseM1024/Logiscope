# LogiScope · 实机验证清单

> 这份是**给手用的**：照着做一遍，逐条打勾或记下现象。
> 目标定义见 [`GOALS.md`](GOALS.md)，原理见 [`ARCHITECTURE.md`](ARCHITECTURE.md)。

## 怎么跑

```bat
cd /d D:\dev\logiscope
gradlew.bat runClient
```

或生成脱离 Gradle 的启动脚本（更适合反复重启测试）：

```bat
gradlew.bat createLaunchScripts
build\moddev\runClient.cmd
```

**准备**：创造模式 + 一个箱子 + 几组物品（建议两组不同物品，比如铁锭和铜锭）。

**当前 `run/mods/` 里装的**：`jei-1.21.1-neoforge-19.21.2.313.jar`（测搜索框冲突必须要它）。

> 注：B7–B9 的转发只覆盖**鼠标**。键盘侧的容器操作（数字键换物品、`Q` 丢弃、

> （背景图层渲染时鼠标坐标被传成 `MAX_VALUE`）—— 见 `ARCHITECTURE.md` CP8「已知限制」。
> 想用这些键就先收起面板。

## 发现问题时怎么反馈

把这三样一起给出，定位速度差 10 倍：

1. **复现步骤**（哪一格、按了什么键）
2. **游戏日志**（`run/logs/latest.log`）
3. **面板上的三行关键数字**：`状态` / `samples X  no-data Y` / `now`

如果怀疑是按键/界面问题，再补一条：`]` 有没有被当成字符输进文本框。
若怀疑是第三方搜索框没被拦住，把**那个搜索框所属模组的名字和版本**也带上 ——
`TextInputGuard` 里每支持一个搜索类模组都要单独加一个探针（目前只接了 JEI），见该文件注释。
