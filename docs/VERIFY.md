```bat
cd /d D:\dev\logiscope
gradlew.bat runClient
```

**准备**：
1. 一个有流量的格子（照常）；
2. 一个**已导出的存档**（先在图表页点「存档并停止」生成）；
3. 多导出两份，看根页存档列表的排序与跨存档读取。

## 一、本轮改了什么

| 需求 | 落地 |
|---|---|
| 图例图标**上下分半** | 上半 = 存量线颜色，下半 = IO 线颜色（浅一档）；关掉的那层显示灰。**两层全关时字体才变暗**（单关一层时这行图例还是亮的） |
| G4 波形标记 | **右键**波形加标记；右键已有标记（±3px）删除。标记独立于环形缓冲（写满不覆盖），随记录导出 |
| G4 悬浮读数 | 光标停在标记附近：`M 2871t · 143.6s  iron 64 · gold 128`（tick / 换算秒 / 各可见线的值，只开 IO 的线报 Δ） |
| G5 导出 | 图表页「存档并停止」：导出 → 停止记录并删探针与缓存 → 直连进入回放页。目录 `.minecraft/logiscope/<存档名>/`（时间戳命名），recording.json + recording.csv |
| G5 回放 | 根页下半 = 存档列表（上半仍是 running probes）；点任意存档进入回放页（跨存档读取）。回放页复用图表全部交互，图例弹窗多一项「分析」选中曲线（可扩展点） |

## 二、复测项（★ = 直接对应本轮改动，优先测）

### A. 图例分半图标（★）

| # | 操作 | 期望 |
|---|---|---|
| ★A1 | 看任一非 (empty) 图例块 | 图标分上下两半：上半 = 存量色，下半 = IO 浅色；关掉的那层是灰的 |
| ★A2 | 弹窗里只开 IO（数量关） | 上半变灰、下半亮，**字体仍是亮的** |
| ★A3 | 弹窗里两层都关 | 上下都灰、字体变暗、底框变暗 |
| ★A4 | (empty) 的图例块 | 仍是单块图标（它没有 IO），关掉时变暗 |
| A5 | 切换各状态时图例不闪 / 位置不动 | 与之前一致 |

### B. 波形标记（★ G4）

| # | 操作 | 期望 |
|---|---|---|
| ★B1 | 右键波形空白处 | 打一条品红竖线 + 顶部小旗；同一 tick 重复右键不叠加 |
| ★B2 | 右键已有标记（±3px 内） | 删除该标记 |
| ★B3 | 光标停在标记附近 | 读数 `M 2871t · 143.6s  iron 64 …`（≤3 条可见线 + `+N`；只开 IO 的线报 `Δ±n`） |
| ★B4 | 把 `bufferSamples` 改小（或记录超过容量）让缓冲滚动 | 标记**还在**（独立于环形缓冲） |
| ★B5 | 框选两段（含标记所在 tick 前后） | Δ / 速率照常（G4 的差值需求沿用框选统计） |
| B6 | 左键拖动框选不受右键标记影响 | 框选照常工作 |

### C. 导出与「存档并停止」（★ G5）

| # | 操作 | 期望 |
|---|---|---|
| ★C1 | 图表页点「存档并停止」 | 记录被导出；探针从列表消失（停止记录 + 缓存清掉）；面板**直接进入回放页**，显示的就是刚导出的数据 |
| ★C2 | 检查 `.minecraft/logiscope/<时间戳>/` | 有 `recording.json` + `recording.csv`；runClient 下在 `run/logiscope/` |
| ★C3 | 打开 recording.csv | `tick,item_id,count`；no_data / gap 行 **count 留空**（不是 0）；尾部有 `# marker <tick>` 注释行 |
| ★C4 | 打开 recording.json | 有 `format/kind/created/world/probe/range/markers/samples`；`markers` 里是右键打的标记 tick |
| ★C5 | 暂停状态下点「存档并停止」 | 导出的就是暂停时那份冻结的数据 |
| ★C6 | 导出失败路径（把目录改成只读文件等极端办法，可跳过） | 导出失败 → 提示"导出失败·探针保留"，探针与数据**还在** |
| C7 | 空探针（无记录）时按钮 | 「存档并停止」是灰的 |

### D. 回放页（★ G5）

| # | 操作 | 期望 |
|---|---|---|
| ★D1 | 回放页信息区 | 存档名 + 导出时间 / 探针描述 / ticks·no-data·series |
| ★D2 | 回放页波形交互 | 缩放 / 全览 / 框选 / 十字线 / 图例（数量 / IO）全部可用；没有「实时」「暂停」「清空」这类活数据才有的按钮 |
| ★D3 | 回放页图例弹窗 | 多一项「分析」：选中后图例块描品红边、信息区显示"分析 iron_ingot"；再点一次取消 |
| ★D4 | 回放页右键 | 加 / 删标记照常（只改内存，不写回存档文件） |
| ★D5 | 回放页点「列表」回根页 | 上半 = running probes、下半 = 存档列表；当前回放的存档有品红左边条 |
| ★D6 | 点存档列表里**另一份**存档 | 跨存档读取：回放页换成那份数据（列表按时间倒序，最新在最上） |
| ★D7 | 存档开着时再按 F9 呼出 / 收起再开面板 | 回放页状态保持；关游戏重开则从存档列表重新载入 |

## 三、报问题时的三件套

1. **复现步骤**（哪台设备、哪一格、`/tick rate` 多少、哪个页面）
2. **`run/logs/latest.log`**
3. **面板数字 / 存档名**：回放问题附上存档目录名；
   标记问题附上"当时是加还是删、光标离标记多远"。
