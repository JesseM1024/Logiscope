## 一、本轮改了什么

| # | 需求（实测反馈） | 根因 / 落地 |
|---|---|---|
| 1 | MEK 机器点 **2 个原料格 + 2 个输出格**，「完成」后却跟到 **1 个原料格 + 全部输出格** | **根因**：`Slot#getContainerSlot()` 在 Mekanism 上**恒为 0**（字节码：`InventoryContainerSlot` 构造时 `super(emptyInventory, 0, x, y)`），而旧规则把它当**最高优先级**判据 → 撞上 slot 0 的格互相覆盖（塌成一格），撞不上的格退回"全纳入"（炸成全部）。<br>**修法**：改用**顺序 + 内容**对齐（新纯类 `analysis/SlotAlign`）：菜单里非空的机器格（按菜单顺序）与数据元素（按 slot 升序）**同序**，取按物品 id 的最长公共子序列，**唯一解才采用**；容器下标降级为备用判据，且要求"该清单下标不重复 + 那个 slot 的元素就是这一格的物品" |
| 2 | 回选格页再点「完成」应该是**覆写**，不是追加/更新 | `ProbeInstance.replaceSlotAnchors`：只换锚点（数据页的 FE/流体目标保留）；**一格都没解出来时什么都不动**；进页面时把已有锚点**回填成勾选状态**（否则覆写会误清） |

**离线代理指标**（`dev-check/TestChart` t33，MEK 9 进 9 出的形状，菜单前两个是空着的虚拟槽）：

| 断言 | 旧规则 | 新规则 |
|---|---|---|
| 两个原料格 → | slot 0、slot 0（**塌成一格**） | slot 0、slot 1 |
| 两个输出格 → | 全部同物品格（**炸开**） | slot 9、slot 10 |
| 空格子 → | 容器下标 0（**错**） | 由统一位移推出 slot 4；推不出来就不选 |

## 二、复测项（★ = 本轮重点）

### G6-B4. 第十六轮④：NBT 槽位型机器取格（★ 优先）

**准备**：Mekanism 终极熔炼工厂（或任何 9 进 9 出的 MEK 机器），输入格放料、输出格有产物。

| # | 操作 | 期望 |
|---|---|---|
| ★N1 | 打开机器 GUI → 打开面板 → 选格页 | 信息行有"NBT 槽位型，按 slot 监测 (N)"；「NBT 追踪」按钮可点（默认可能是**开** —— 这是纯锚点探针，见 N5） |
| ★N2 | **只点 2 个有物品的原料格 + 2 个有物品的输出格** → 完成 | **只建 4 条目标**（不是 5 条、也不是十几条）。提示里的数字 = 当前目标总数 = 4 |
| ★N3 | 看图表页 `now` 行 / 数据页目标列表 | 四个目标的值分别对应**那四格**的数量（不是别的格、也不是同物品求和后的一个数） |
| ★N4 | 同物品占了**多格**（例如 9 个输入格全是同一种料），只点其中 2 格 | 仍然**只建 2 条**（不是"全部同物品格"） |
| ★N5 | 从图表页点「选格」再进来 | NBT 追踪**自动是开**的，且**刚才那 4 格已经勾着**（不必手动开） |
| ★N6 | 在 N5 状态下**加勾 1 格** → 完成 | 变成 5 条（4 保留 + 1 新增） |
| ★N7 | 在 N5 状态下**取消勾 1 格** → 完成 | 变成 3 条（被取消的那条**真的删掉了**）—— 这是"覆写"的关键 |
| ★N8 | 一格都不勾 → 完成 | **什么都不变**，提示"先勾格子…"（不会把已有目标清空） |
| N9 | 点一个**空格子** → 完成 | 若位移能从别的格子推出来 → 该格也成为一条目标（初始值 0）；推不出来 → 提示跳过 N 格，**不建** |
| N10 | 让某条被监测的格子被抽空 / 再放回同种物品 | 抽空 → 该线变 **0**（不是断档）；放回同种 → 同一条线继续 |
| N11 | 抽空后放回**另一种**物品 | **新开一条线**（旧线停在 0） |
| ★N12 | 反复开关机器 GUI | 四条线的读数**始终一致**（这一路完全不碰菜单） |
| N13 | 数据页加一个 NBT 路径目标（如 `energy`），再回选格页改勾选 → 完成 | 锚点被覆写，但**那个路径目标还在**（两条线互不干扰） |
| N14 | 机器**不装升级**与**装了升级/放电池**两种情况 | 都能正确定格（虚拟升级槽、能量槽是空的时候不进对齐序列） |
