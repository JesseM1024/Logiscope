## 怎么跑

```bat
cd /d D:\dev\logiscope
gradlew.bat runClient
```

**准备**：
1. 一个有产线的存档（能持续进/出物品），最好也有一台 Mek 设备（数据线）；
2. 记 FPS 的快捷键开着（F3 或你惯用的 HUD）；
3. 跑内存测试时**别挂机在暂停界面**（暂停时世界不走 tick，测不出泄漏）。

## 一、本轮改了什么

| # | 需求 | 落地 |
|---|---|---|
| 1 | 多线掉帧（实测：多物品多 IO 线 **20 FPS**） | 渲染路径三条优化（全部**像素等价**）：① 列标记改代际戳（省掉每帧 7 万次无用写入）；② 只扫"有数据的列"（不再全宽空转）；③ **游程合并后再 fill**（台阶数据 99.3% 降幅、混合场景 63.8%）。列聚合整段搬进纯类 `WaveColumns`，离线可断言/可压测 |
| 2 | 换维度的语义（用户口径） | **进世界 = 加载存档**（那时清空探针）；游戏内**切维度不算换世界**：区块加载了就继续采，没加载就按卸载走（`no-data`）——与 CP9 的"该断的地方要断"一致 |

**离线代理指标**（`dev-check/BenchRender`，50 线 × 700 列）：

| 数据形状 | 合并前 fill/线 | 合并后 | 降幅 |
|---|---|---|---|
| 台阶（物品存量 / 液位） | 1399 | 10 | 99.3% |
| 阶梯（罐子逐格进料） | 1399 | 120 | 91.4% |
| 噪声（FE 能量逐 tick） | 1399 | 698 | 50.1% |
| 流量（IO 多为 0） | 1399 | 210 | 85.0% |
| 混合（实机近似） | 1399 | 507 | 63.8% |

## 二、复测项（★ = 本轮重点）

### G6-A. 性能（★）

| # | 场景 | 优化前基线 | 期望 |
|---|---|---|---|
| ★A1 | 默认（不打开面板） | 1300 | ≥ 1200（不该被模组拖累） |
| ★A2 | 打开面板（根 UI） | 850 | ≥ 800 |
| ★A3 | 单线图表 | 300 | ≥ 300（不应回退） |
| ★A4 | 双线图表（存量 + IO） | 200 | ≥ 250 |
| ★A5 | **大量图表（多物品多 IO 线，≥ 20 条可见线）** | **20** | **≥ 60**；形状偏台阶时应更高 |
| ★A6 | 同一场景下波形**像素与改前一致**（台阶没被抹平、尖峰还在、断档仍空白） | — | 视觉无差异（这是优化的硬约束） |
| A7 | 缩放到很窄的窗口（窗口里只有几十个点） | — | 不再出现明显掉帧（对应"只扫有数据的列"） |

> 报数时请写清：**可见线条数**（图例里的条数）+ **数据形状**（物品存量 / 流体 / FE / IO）
> —— 噪声型数据（每 tick 都变）的合并空间天然小，这是已知边界（CP21 / PROGRESS）。

优化效果已确认，29线仍有330帧

### G6-B. 稳定性（★）

| # | 操作 | 期望 |
|---|---|---|
| ★B1 | 连续记录 **30 分钟**（3 格物料线 + 1 条数据线同时跑），中途每 5 分钟记一次内存 | 内存平稳（环形缓冲不涨）；无卡顿累积；面板操作仍然跟手 |
| ★B2 | 让环形缓冲写满（`bufferSamples` 调小，如 2000） | 最旧样本被覆盖、界面不报错；曲线照常滚动 |
| ★B3 | **死亡** → 复活 | 采样继续（若探针绑定的是方块，复活后回来看曲线应有连续记录） |
| ★B4 | **同维度内切换维度**：去地狱 → 回主世界（区块**已加载**） | 采样继续，曲线不断（探针按坐标读设备，与玩家在哪无关） |
| ★B5 | 去一个**没加载**的维度（或把目标设备所在区块卸掉） | 按卸载走：`no-data` 增长、曲线断开；回到加载状态后**自动恢复**（不断永久） |
| ★B6 | 关掉面板后长时间 `FOLLOWING`（≥ 10 分钟，最好跑出 1 万个 tick） | 内存不涨（`WorldProbe` 缓存不堆积）；重新打开面板数据连续 |
| B7 | 与其他客户端模组共存（JEI / REI / Jade 等） | 无冲突（**已勾，作为回归**） |

B5: 目前前往其他维度、同维度1000格外卸载，对于原版容器、模组容器、方块实体nbt均会持续写入卸载前的数值。


### G6-B2. 第十四轮改动（★ 优先）

| # | 操作 | 期望 |
|---|---|---|
| ★B5b | 走到设备**模拟距离外**（不必卸载整个区块） | `no-data` 开始增长（**不再**写静止的旧值）——这是 B5 的修法，判据换成"方块 tick 范围" |
| ★B5c | 换维度（地狱 / 末地）再回来 | 出范围期间 `no-data`；回到范围内**自动恢复** |
| ★W1 | 普通容器（格子序号互不相同）里点几个不同序号的格，包括空格子 | **不再弹**"下标不可信"提示 |
| ★W2 | MEK 那类"全是 #0"的容器（或任意序号有重复的） | 仍然提示（这是真正需要提醒的情形） |
| ★W3 | 图表页信息行第 3 行 | 显示 `样本 N / 上限 M`；原来那行 `min/max/avg` 不再出现 |
| ★W4 | 回放页工具栏 | 多出「重命名」按钮 |
| ★W5 | 点「重命名」→ 改名 → Enter | 输入框消失、标题与根页列表都显示新名字；重启游戏后仍然是新名字（写在 `name.txt`） |
| ★W6 | 改名时按 Esc | 取消，名字不变 |
| ★W7 | 根页存档列表 | 三列对齐：名称（左侧较宽）/ 文件夹 / 样本数（右对齐），列名在标题行右侧 |
| ★W8 | 悬浮图例的 `+3` | 弹出被收起的线名清单 |
| ★W9 | 悬浮探针行的 `数据 x1` | 弹出该探针追踪的 NBT 键（路径 ← 名称路径） |
| ★W10 | 悬浮选格页第一行的 `槽 0,1,2+24` | 弹出全部已选格子（`槽 n · 物品 x数量`） |
| ★W11 | 上面任一详情很长时在框内滚轮 | 内容上下滚动（底部显示 `x / y`），且不吃掉别处的滚动 |
