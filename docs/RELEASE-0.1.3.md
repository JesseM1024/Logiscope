# LogiScope 0.1.3

纯客户端物流示波器：把容器 / 机器的**物品存量**与 **NBT 数值**画成波形，用来看产线到底在不在动、什么时候开始堵。
不装服务端、不发网络包，读的是客户端本来就同步下来的数据（单人下关掉界面也能继续读方块实体）。

五条线统一到 0.1.3：`0.1.3-1.21.1` · `0.1.3-1.20.1` · `0.1.3-1.18.2` · `0.1.3-1.16.5` · `0.1.3-1.12.2`
（**后两条是本版首次发布**；1.20.1 / 1.18.2 去掉 `-alpha`）

## 相对 0.1.2 的变化

**AE2 从"不能用"到"能用"**（本版最大的一块）
0.1.2 的发布说明里写得很清楚：1.20.1「AE2 物品读取功能失效，暂未完成兼容」、1.18.2「AE2 功能仍然失效」。
本版五条线全部打通：

- 终端里的每一格按**真实数量**读（不再恒 `x1`；真值在 `getAEStack().getStackSize()` 及其它代的等价接口）
- **非物品键（流体 / 化学品）显示真名 + 真值** —— 以前它们在客户端会被包成同一个东西，
  表现为 `x1`、而且点一行会把全部选中
- 除 1.12.2 外，**关掉终端后仍能继续读**（服务端直接查网络，不依赖界面同步）

**选格**
- 选格页新增**筛选框**：物品名或 `#序号`（如 `#1 iron_ingot`），空格分词取"与"；`#1` 不会命中 `#10`
- 新增**「忽略空槽」**开关，与文字筛选叠加

**回放**
- 回放页新增**「打开存档文件夹」**：直接落到这一次的 `recording.json` / `.csv` 所在目录

**界面**
- 悬浮详情框限制在**游戏窗口内**、长文本**自动折行**（以前长说明会顶到屏幕右侧被切掉）

**内部**
- 反射边界统一：**原版方法一律直接调用，只反射 AE 自己的方法** —— 顺带修掉 1.20.1 生产环境
  （SRG 命名）AE 键解析整链失效的 bug（原来反射了 `TagParser#parseTag`，生产叫 `m_129359_`）

## 与 main 的差异

| 线 | 差异 |
|---|---|
| **main**（1.21.1） | 基准线。AE2 19.x |
| **1.20.1** | AE2 15.x。上面那条 SRG 反射 bug 就出在本线（生产必扑空） |
| **1.18.2** | AE2 **11.7.6**：`GridHelper#getNodeHost` 收 `LevelAccessor`（12+ 才改成 `Level`），照抄高版本签名会扑空（已修）；没有 `BuiltInRegistries` |
| **1.16.5**（首次发布） | AE2 **8.4.7 是另一套 API**（`IGridHost → getGridNode → IGrid#getCache → IMEInventory`）；流体是 `ae2:fluid_dummy` 占位物品，身份必须走 `RepoSlot#getEntry`；终端一打开就把焦点交给搜索框 ⇒ 快捷键判据改成"F1–F25 永不被文本框挡"；只能用 log4j2 |
| **1.12.2**（新线，首次发布） | MC 1.12.2 + Forge 14.23.5.2859（ForgeGradle 3 / Gradle 4.9 / JDK 8）。面板是"**真图层**"（不替换当前界面，容器的 tick 与别的模组的界面都正常）；**关掉容器界面后仍能继续追踪**（单人）；双联箱子按 54 格读；AE2 **rv6** 能读终端里的物品/流体真值，但**还不能直接读 AE 网络**；**可视化选格暂不可用**（按钮置灰 + 悬浮说明，请用复选框按序号/名字选） |

## 已知限制

- **1.12.2**：AE 探针只在终端界面开着时读数（关掉终端记 `no-data`）；可视化选格暂不可用；
  NBT 槽位模式对双联箱子只覆盖半只（普通槽位模式正常）
- **MEK 的 NBT 槽位模式**（1.18.2 及以后）：仍要求格子里先有物品，才能把 NBT 里的容器序号对上
  （与 0.1.2 相同）
- **全平台**：多人游戏下读不到设备 NBT、关掉界面后读不到容器内容（纯客户端模组的固有边界）
- **全平台**：AE 读值是"全量扫一遍 + 同 tick 缓存"，超大网络下每 tick 成本随键数增长
