# LogiScope 0.1.3

纯客户端物流示波器：把容器 / 机器的**物品存量**与**NBT 数值**画成波形，用来看产线到底在不在动、什么时候开始堵。
不装服务端、不发网络包，读的是客户端本来就同步下来的数据（关掉界面后单人可继续读方块实体）。

> **关于版号**：`0.1.2` 从未单独发布，它的改动已并入本版；下面按"相对 0.1.1"列。
> 五条线统一到 0.1.3：`0.1.3-1.21.1` · `0.1.3-1.20.1` · `0.1.3-1.18.2` · `0.1.3-1.16.5` · `0.1.3-1.12.2`。

## 新增 / 变化

**选格**
- 选格页新增**筛选框**：支持物品名或 `#序号`（如 `#1 iron_ingot`），空格分词取"与"；`#1` 不会命中 `#10`
- 新增**「忽略空槽」**开关，与文字筛选叠加使用
- 回放页新增**「打开存档文件夹」**：直接落到这一次的 `recording.json` / `.csv` 所在目录

**AE2**
- 非物品键（流体 / 化学品）现在显示**真名 + 真值** —— 以前所有非物品键在客户端会被包成同一个东西，表现为 `x1`、且点一行把全部选中

**DATA 页（NBT 取数）**
- 可直接在 DATA 页点「完成」创建探针，不必先回选格页
- NBT 刷新速率 **1–40 tick 可调 / 可关闭**
- 右键路径 →「**按数值读取**」：以字符串存的数字（`"1000"`）也能按数值采样；转不出来记 `no-data`，**不伪造 0**

**采样**
- 物品探针统一到**服务端 tick** 采样：读数与时间戳同源，消除漏观测与时间戳跳格造成的"假断线"；界面读取降为兜底

**界面**
- 悬浮详情框限制在**游戏窗口内**、长文本**自动折行**（以前一行长说明会顶到屏幕右侧被切掉）

## 与 main 的差异

| 线 | 差异 |
|---|---|
| **main**（1.21.1） | 基准线。AE2 19.x |
| **1.20.1** | AE2 15.x。**本线额外修了一个真 bug**：AE 键解析在生产环境（SRG 命名）整链失效 —— 旧代码反射了原版 `TagParser#parseTag`（SRG 下叫 `m_129359_`），生产必扑空。现在"原版方法直接调，只反射 AE 自己的方法" |
| **1.18.2** | AE2 **11.7.6**：`GridHelper#getNodeHost` 收 `LevelAccessor`（12+ 才改成 `Level`），照抄高版本签名会扑空（已修）。没有 `BuiltInRegistries`，物品查询走 `ForgeRegistries` |
| **1.16.5** | AE2 **8.4.7 是另一套 API**（`IGridHost → getGridNode → IGrid#getCache → IMEInventory`）。流体是 `ae2:fluid_dummy` 占位物品，身份必须走 `RepoSlot#getEntry`。AE 终端一打开就把焦点交给搜索框 ⇒ 快捷键判据改成"F1–F25 永不被文本框挡"。只能用 log4j2（slf4j 装进实例即崩） |
| **1.12.2**（新线，本版首次发布） | MC 1.12.2 + Forge 14.23.5.2859（ForgeGradle 3 / Gradle 4.9 / JDK 8）。面板是"**真图层**"（不替换当前界面）；**关掉容器界面后仍能继续追踪**；双联箱子按 54 格读；AE2 **rv6** 能在终端里读物品/流体真值，但**还不能直接读 AE 网络**；**可视化选格暂不可用**（按钮置灰 + 悬浮说明，请用复选框按序号/名字选） |

## 已知限制

- **1.12.2**：AE 探针只在终端界面开着时读数（关掉终端记 `no-data` —— ME 网络不在方块物品栏里）；可视化选格暂不可用；NBT 槽位模式对双联箱子只覆盖半只（普通槽位模式正常）
- **全平台**：多人游戏下读不到设备 NBT / 关界面后读不到容器内容（客户端进程里没有那些数据，这是纯客户端模组的固有边界）
- **全平台**：AE 读值是"全量扫一遍 + 同 tick 缓存"，超大网络下每 tick 成本随键数增长
