# LogiScope 1.0.0

纯客户端物流示波器：把容器 / 机器的**物品存量**与 **NBT 数值**画成波形，用来看产线到底在不在动、什么时候开始堵。
不装服务端、不发网络包，读的是客户端本来就同步下来的数据。

五条线统一到 1.0.0：`1.0.0-1.21.1` · `1.0.0-1.20.1` · `1.0.0-1.18.2` · `1.0.0-1.16.5` · `1.0.0-1.12.2`

---

## 相对 0.1.3 的变化

### 新增：精致存储（Refined Storage）网络采样
- 和 AE 一样支持**网络级**监测：对着网格方块打开界面，在选格页勾选条目后点「完成」，之后曲线读的就是这张网络里的存量。
- 物品与流体都支持，关掉界面照样读；断电 / 未接通记为读不到，网络里没有这个东西记为 0，两者严格区分。
- 1.20.1 / 1.18.2 / 1.16.5 / 1.12.2 四条低版本线同步支持。

### 界面与交互
- **名称显示开关**：选格页、图表页、计算页各有一个「名称: 实际名 / 注册名」按钮，三处联动并记进配置。
  实际名是游戏内名字（水 / 铁锭），注册名是 `water` / `iron_ingot`；只改显示，不影响已记录的曲线和存档。
- **追踪目标高亮**：根页每个探针旁多出一个十字准星按钮，按下会在世界里画出这台设备的方块边框，红黄闪烁、穿墙可见。
  只在同一维度且三轴距离都小于 128 格时显示，走远了只是不画、状态保留，再点一次取消。
- **存档删除**：根页存档列表每行行尾多了 ×，点一次先提示确认、再点一次才真的删（连同上一次的记录文件），点别处取消。

### 修复
- 修掉在「拿不到方块坐标的界面」（如无线终端）里选完目标点「完成」时的崩溃。
- 用便携网格这类**不是对着设备方块**打开的界面时，点「完成」会被拒绝并说明原因，
  不再存下一个永远读不到数据、界面上却毫无提示的目标。

### 其它
- 模组列表里显示自己的图标。
- 五条版本线功能对齐：名称开关、目标高亮、存档删除、精致存储采样在全部五条线上都可用。

---

## 已知限制
- 多人游戏下读不到设备 NBT，关掉界面后读不到容器内容（纯客户端模组的固有边界）。
- AE / 精致存储的读值每次采样都会扫一遍网络，超大网络下开销随条目数增长。
- 精致存储按 NBT 区分条目：同名物品只要 NBT 不同就是两条独立曲线（刻意如此，合并会读出假值）。
