# LogiScope · 待办与候选（滚动）

> 本文件装**正式目标之外**的待办：待优化项 / 未测项 / 已接受限制的可升级候选 / 新功能候选。
> 正式目标的未完成项见 [`GOALS.md`](GOALS.md)（当前只剩 G6 的长时间四项）；
> 历轮已完成事项见 [`PROGRESS-HISTORY.md`](PROGRESS-HISTORY.md)。

## 一、待优化项（实现层，方向已明确）

| # | 项 | 现状 / 落点 |
|---|---|---|
| B1 | **NBT 采样每 tick 构建整份 NBT，再按路径取一个值** | 要动的只有 `DataProbe#readNumber` 一处，接口不变。方向：只取需要的子标签、路径前缀先对一遍、缓存路径父节点引用。多目标 + 高频采样时这是唯一的性能热点 |
| B2 | `data get block` 那一侧（界面上实时显示）无法"只取一个值" | 原版命令语义决定，只能靠 B1 在采样侧绕开（已知边界） |
| B3 | 图例超 3 行会收成 `+N` | 已接受（罕见场景）；如要改，需在图例区加滚动（ARCHITECTURE 待决问题 5） |
| B4 | 纵轴范围偶尔跳变 | 自动缩放的固有代价，已吸附整数刻度；如要彻底稳，可加"锁定纵轴范围"开关 |

## 三、已接受限制（可升级候选）

| # | 项 | 代价 / 依赖 |
|---|---|---|
| D1 | 面板打开时容器**键盘**操作无效（数字键 / `Q` / 中键） | 要连 `hoveredSlot` 一起补，属 GUI 图层栈深水区（CP8） |
| D2 | 用快捷键开界面的模组拿不到方块坐标 | 已由准星入口缓解（CP17）；根治要拦更多入口 |
| D3 | 多人下容器内容只在菜单打开期间同步 | 记 `no_data`；要真做需要服务端配合 |
| D4 | 第三方搜索框（JEI 之外）需逐个加探针 | 第 3 层通用兜底已覆盖（代价：打字后多按一次） |
| D5 | 同 tick 一进一出时 IO 线显示 0 | 可观测量的边界（CP18）；替代方案 = 同时监控上下游容器（多探针 / 多目标已支持） |
| D6 | 环形缓冲按**样本条数**计，一个实例多种物品共用 | 多格多物品时每种留 1/N；要改需按"每条线"独立缓冲（数据层重构） |
| D7 | 自绘界面模组数值不对 | 对方把内容放在自定义包里，需要专门适配 |

## 四、新功能候选

| # | 候选 | 理由 | 规模 |
|---|---|---|---|
| E1 | DATA 页**路径即时校验** | 路径写错目前只表现为"曲线全 no-data"；拿到 NBT 树时可当场标红 | 小 |
| E2 | 存档管理（列表内删除 / 重命名 / 重新导出） | 现在只能去文件管理器删；存档只增不减 | 中 |
| E3 | 多探针对比视图 | 多探针已能同时记录，缺"同屏比较"入口；需要相对时间轴（ARCHITECTURE 待决问题 6） | 中 |
| E4 | 选区统计加"跨线合计行" | 多目标同图时常想看总和；`visibleSelectionStats` 已能拿到全表 | 小 |
| E5 | 纵轴锁定 / 固定范围 | 配合 B4，长时间观察曲线不上下伸缩 | 小 |

## 五、优先级建议（可推翻）

1. **实机复测**（[`VERIFY.md`](VERIFY.md) 现行清单：十六⑦⑨ / 十七① / 十八①-④）—— 先清欠账，再谈新功能。
2. **B1 + E1** —— 一处实现 + 一处小功能，都是 DATA 页这条线的手尾。
3. **C1 / C2 / C3** —— 三条老账，顺手就能验。
4. **E2 / E3** —— 体验型，用得越久越想要。
